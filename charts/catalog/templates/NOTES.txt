Реліз {{ .Release.Name }} (чарт {{ include "catalog.chart" . }}, образ {{ .Values.image.repository }}:{{ include "catalog.imageTag" . }}) встановлено в namespace {{ .Release.Namespace }}.
Середовище: {{ .Values.config.environment }}, реплік: {{ .Values.replicaCount }}.

Перевірити стан подів:
  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

Як відкрити застосунок:
{{- if .Values.ingress.enabled }}
  1) В окремому терміналі (від адміністратора): minikube tunnel
  2) Додати в C:\Windows\System32\drivers\etc\hosts рядок: 127.0.0.1 {{ .Values.ingress.host }}
  3) Відкрити: http://{{ .Values.ingress.host }}/api/v1/catalog/config
{{- else if eq .Values.service.type "NodePort" }}
  minikube service {{ include "catalog.fullname" . }} -n {{ .Release.Namespace }} --url
  і відкрити <отримана адреса>/api/v1/catalog/config
{{- else }}
  kubectl port-forward svc/{{ include "catalog.fullname" . }} 8080:{{ .Values.service.port }} -n {{ .Release.Namespace }}
  і відкрити http://127.0.0.1:8080/api/v1/catalog/config
{{- end }}

  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
